# Changelog

## 0.2.2

- Adds an independent Show in Menu Bar setting alongside Show in Dock.
- Reopening the app from Spotlight or Finder always opens Settings, even with both icons hidden, without changing either preference.
- Manual launches open Settings; login-item launches stay in the background when Accessibility is available.

## 0.2.1

- Adds a custom macOS app icon for Finder and the Dock, included in the downloadable app.
- Includes the icon artwork and generation script in the source repository.

## 0.2.0

First public release as **Smart Middle Click Autoscroll**.

- Context-aware middle-click autoscroll across compatible macOS apps.
- Native middle clicks preserved for links, tabs, controls, unknown targets, and excluded apps.
- Free pointer movement while scrolling stays directed at the original content location.
- Speed control, horizontal scrolling, and per-app exclusions in the menu bar.
- Compact setup screen, separate diagnostics, and built-in help.
- Optional Start at login through macOS Login Items.
- Dock access and an Options button for crowded menu bars.
- Universal Apple Silicon and Intel app, source, automated checks, and a local test page.
